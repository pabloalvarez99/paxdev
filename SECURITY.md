# Security policy

This is a static public portfolio with no login, form, database, analytics collector, or runtime
secret. Do not include credentials in an issue, screenshot, commit, or deployment log.

Report a vulnerability privately through the repository's GitHub Security Advisory flow:

<https://github.com/pabloalvarez99/paxdev/security/advisories/new>

Include the affected URL, a minimal reproduction, and impact. Never include a real credential or
personal data in the report.
